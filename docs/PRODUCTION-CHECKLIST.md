# قائمة التحقق للإطلاق الإنتاجي — منصة «خمسة برمجة بالبلدي»
# Production Launch Checklist

استخدم هذه القائمة لمراجعة كافة عناصر النظام قبل وبعد توجيه النطاق الفعلي إلى خوادم الإنتاج:

---

## 1. قواعد البيانات والتخزين السحابي (Database & Cloud Storage)
- [ ] إنشاء MongoDB Atlas Cluster وتأمين المستخدمين بكلمات مرور قوية.
- [ ] إضافة IP خادم الإنتاج إلى IP Access List في MongoDB Atlas.
- [ ] إنشاء Cloudflare R2 Bucket وتعيين Custom Domain للـ CDN (`media.khamsa.dev`).
- [ ] إنشاء R2 API Token بصلاحيات القراءة والكتابة فقط وتوثيق الـ Keys في `.env`.
- [ ] التأكد من قيود حجم الملفات (Max 10MB) والأنواع المسموحة (JPEG, PNG, WEBP, AVIF).

---

## 2. إعدادات الخادم والأمان (Server & Security Configuration)
- [ ] ضبط `NODE_ENV=production` في بيئة الخادم.
- [ ] توليد مفاتيح JWT عشوائية وقوية (`JWT_ACCESS_SECRET` و `JWT_REFRESH_SECRET` لا تقل عن 32 حرفاً).
- [ ] إعداد روابط CORS المصرح لها فقط في `CLIENT_URL` بدون السماح بـ `*`.
- [ ] تفعيل ملفات تعريف الارتباط الآمنة (`secure: true`, `httpOnly: true`, `sameSite: 'none'`).
- [ ] تفعيل وترقية شهادات SSL / HTTPS لجميع النطاقات الفرعية.
- [ ] تفعيل Security Headers (HSTS, CSP, X-Frame-Options, X-Content-Type-Options).
- [ ] تفعيل Rate Limiting على مسارات تسجيل الدخول والـ API العامة.

---

## 3. الواجهة الأمامية وتجربة المستخدم (Frontend & UX)
- [ ] ربط `NEXT_PUBLIC_API_URL` و `NEXT_PUBLIC_SITE_URL` بالنطاقات الحقيقية.
- [ ] التحقق من استجابة جميع صفحات الموقع العامة (`/`, `/about`, `/articles`, `/videos`, `/articles/[slug]`).
- [ ] التأكد من عمل مشغل فيديوهات اليوتيوب، التيك توك، والفيسبوك بدون أخطاء CSP.
- [ ] التحقق من تناسق الوضعين الداكن والفاتح (Dark / Light) بدون FOUC أو Hydration Mismatch.
- [ ] التأكد من خلو واجهة المستخدم من أي إيموجيز واعتماد أيقونات Lucide حصرياً.
- [ ] التأكد من دعم RTL وخط Cairo في كافة الشاشات والأجهزة.

---

## 4. لوحة الإدارة ونظام إدارة المحتوى (Admin Dashboard & CMS)
- [ ] تسجيل الدخول بحساب المشرف والتحقق من حفظ واسترجاع التوكن عبر الـ HTTPOnly Cookies.
- [ ] إنشاء وتعديل ونشر مقال تجريبي باستخدام محرر Tiptap والتحقق من الـ AST JSON.
- [ ] رفع صورة غلاف ومحتوى إلى Cloudflare R2 والتأكد من ظهورها برابط CDN مباشر.
- [ ] إضافة وتعديل فيديو سوشيال ميديا والتحقق من التضمين.
- [ ] إدارة المستخدمين وتغيير كلمة المرور والتحقق من حماية آخر مشرف نشط.
- [ ] تعديل وحفظ إعدادات المنصة والهوية والسوشيال ميديا وتحديث الواجهة العامة.

---

## 5. محركات البحث والأداء (SEO & Performance)
- [ ] التحقق من صلاحية ملف `sitemap.xml` وظهور المقالات المنشورة بداخله.
- [ ] التحقق من حجب `/dashboard` و `/login` و `/api` في ملف `robots.txt`.
- [ ] التحقق من صحة بطاقات OpenGraph و Twitter عند مشاركة الروابط.
- [ ] فحص بيانات JSON-LD المنظمة (Organization, WebSite, Article, Breadcrumbs).
- [ ] اختبار سرعة التحميل وCore Web Vitals على Google PageSpeed Insights.

---

## 6. الصيانة وخطط الطوارئ (Operations & Monitoring)
- [ ] اختبار نقطة فحص الصحة `GET /health` والتأكد من إرجاع `status: ok` واتصال الـ DB.
- [ ] تشغيل ومراقبة التطبيق عبر PM2 والتحقق من كتابة الـ Logs في مجلد `logs/`.
- [ ] إعداد خطة النسخ الاحتياطي التلقائي اليومي لقاعدة بيانات MongoDB.
- [ ] توثيق خطة التراجع السريع (Rollback Strategy) والتحقق من جاهزيتها.
